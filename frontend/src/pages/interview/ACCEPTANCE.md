## 打开预览

正常预览：构建前端后，按根目录 start.ps1 启动或重启后端（需已安装项目 .venv；也可用已安装依赖的 Python 执行 backend/main.py），打开 127.0.0.1:8000，登录后进入当前名为“面试话术”的入口。先在工作台确认资料、填写 JD 并生成简历，即可选择题库或直接模拟。模型未配置时生成或开始会明确失败，不伪造结果。

只看交互：运行上述 --serve 命令，打开 127.0.0.1:8002，使用脚本启动输出中的合成测试账户。该服务仅用于 Mock，退出后临时数据库清理；不能保存真实材料。前述 Mock 浏览器验收未替换用户原有的 8000 预览进程。

同步 d6f7725 后，核实原 8000 进程的 OpenAPI 缺少 `/api/workspace`，与磁盘上的最新代码不一致。已验证新后端并重启 8000；本次独立入口升级后再次重启并核实 `/api/workspace` 与 `/api/interview/start` 均已注册，匿名工作台请求返回 401（需登录），健康检查正常，不再返回 unknown api route。登录后的保存/恢复由上述临时数据库合约测试覆盖，未写入用户真实工作台。当前真实预览健康检查显示模型未配置；启动和路由正常不代表模型联调通过。
